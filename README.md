
# NOVA — Single Page Application (SPA)

## Project Overview

NOVA is a modern and responsive Single Page Application developed using HTML5, CSS3, and vanilla JavaScript. The project demonstrates how a website can dynamically change its content without reloading the entire page. It features a clean interface, a dark theme with violet accents, smooth transitions, and a futuristic technology-inspired Home section.

This project was developed as part of a Week 5 web development assignment to understand client-side routing, dynamic rendering, browser history, responsive design, and form validation.

## Features

- **Single Page Navigation:** Move between Home, About, Projects, and Contact sections without a full-page reload.
- **Client-Side Routing:** Uses URL hash routes to display the appropriate section.
- **Browser History Support:** Supports the browser Back and Forward buttons.
- **Responsive Design:** Adapts the layout for desktop and mobile screens.
- **Mobile Navigation:** Includes a menu button for smaller screens.
- **Invalid Route Handling:** Displays a helpful error page for unsupported routes.
- **Contact Form Validation:** Checks required fields and email format and displays a demonstration success message.
- **Project Gallery:** Shows four project cards with preview images and technology labels.
- **Visual Effects:** Includes hover effects, smooth scrolling, and a futuristic Home image.

## How to Run

1. Download or clone the project repository.
2. Open the `Week5-SPA` folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the Home, About, Projects, and Contact sections.
5. Test URL routing, browser history, mobile navigation, and the Contact form.

## Limitations

The Contact form is a front-end demonstration only. It validates user input and displays a success message, but it does not send email or store messages on a server. The project does not require a backend or database for its current functionality.

## Learning Outcomes

This project provides practical experience with HTML structure, CSS layouts, JavaScript event handling, hash-based routing, dynamic content rendering, browser history, responsive design, and client-side form validation.
